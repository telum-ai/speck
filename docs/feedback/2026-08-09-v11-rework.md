# Speck Feedback — v11 subtraction proof gaps

**Date**: 2026-08-09
**Speck version (workspace)**: v11.0.0
**Repo HEAD**: `3d68ca1` on branch `feat/v11-subtraction`
**Workspace**: Speck methodology repository (Platform; v11 rework)

## TL;DR

The v11 branch achieved the intended cold-start subtraction but exposed six proof and delivery gaps: candidate-disconnected scoring, fake JIT splits, a repository-local Claude import, an incomplete always-on flow, release-history contamination, and a broken runtime/meta distribution boundary. Rework patches are being applied directly upstream on PR #127.

---

## Gap / Observation V11-1: Fitness score could not observe the candidate

**Symptom**: A1-lite reported 100% after every skill rewrite.

**Reproduction**: Read `tests/eval/score.sh`; every fixture ran its own checker, the process never failed on incorrect verdicts, and `baseline.md` was overwritten after each run.

**Root cause**: The fixture authored both the defect and its detector. No edge connected the score to the candidate skill corpus.

**Severity**: P1

**Patch applied**: Replace fixture-local checkers with a fail-closed central evaluator, candidate-corpus capability anchors, an immutable JSON baseline, and mutation tests.

**Proposed upstream fix**: Shipped in this branch.

**Impact**: The central v11 claim “keep truth-detection” previously had no causal regression signal.

## Gap / Observation V11-2: Shape lint admitted fake load DAGs

**Symptom**: `story-implement` and `story-tasks` passed anti-theater CI while unconditional `spine-2.md` continuations made common invoke paths larger than v10.

**Reproduction**: Run the corpus validator, then total the bytes of router plus all mandatory references for UI and backend paths.

**Root cause**: The validator accepted a multi-reference router when any predicate token appeared anywhere in its body; it did not adjudicate each reference edge.

**Severity**: P1

**Patch applied**: Ban reference-to-reference continuation edges, require explicit router ownership of every node, add reachable-path byte budgets, and collapse duplicated story task/implement paths.

**Proposed upstream fix**: Shipped in this branch.

**Impact**: Invoke-time context grew on the most common story paths while the gate claimed JIT success.

## Gap / Observation V11-3: Claude import was repository-local

**Symptom**: A clean `smartSync` target contained `AGENTS.md` but no `CLAUDE.md`.

**Reproduction**: Invoke `smartSync(source, emptyTarget)` and inspect the target root.

**Root cause**: `CLAUDE.md` was added to the Speck repository but omitted from `SMART_MERGE_FILES`.

**Severity**: P1

**Patch applied**: Add a managed Claude import block, preserving init/upgrade merge, and regression tests.

**Proposed upstream fix**: Shipped in this branch.

**Impact**: Downstream Claude sessions still missed the always-on Speck contract.

## Gap / Observation V11-4: Optional flow slots were not always in context

**Symptom**: `epic-constitution` advertised why it exists but not when it is due; the shortened AGENTS flow omitted it, so an agent could reach `epic-plan` without evaluating the slot.

**Reproduction**: Read root `AGENTS.md` and the `epic-constitution` description, then compare them with the stale flow embedded in `epic-specify` and the fuller JIT-only `command-phases.md`.

**Root cause**: V11 split sequence ownership across an incomplete always-on summary, a JIT reference, skill bodies, and catalog descriptions. The catalog-only evaluator tested obvious intent classification without the actual always-on flow context.

**Severity**: P1

**Patch applied**: Make the complete marked AGENTS flow the single always-on sequence, remove competing flow copies, add local boundaries to phase-bound optional descriptions, and bind routing reports to the exact flow bytes. The adversarial closure replaced the editable presence list with an immutable ordered-route baseline that classifies all automatic skills and mutation-tests omissions, reordering, and unclassified entries.

**Proposed upstream fix**: Shipped in this branch.

**Impact**: Optional methodology steps could be discoverable in isolation yet never activate at their intended point in the lifecycle.

## Gap / Observation V11-5: Always-on context taught release archaeology instead of the current method

**Symptom**: A cold agent met Speck through v8, v9, and v11 north-star links, unexplained gap labels, and a universal native `/goal` claim before it received a plain current operating model.

**Reproduction**: Read root `AGENTS.md` without prior Speck knowledge and follow only the commands and links available in a downstream install.

**Root cause**: Release design notes, host accelerators, current invariants, and compatibility behavior were treated as one always-loaded class.

**Severity**: P1

**Patch applied**: Rewrite AGENTS in present-tense plain language; keep the canonical flow and hard gates always loaded; make `/goal` optional; move release north stars to `docs/history`; keep exact version tokens only where migration markers require them.

**Impact**: Agents can understand and execute current Speck without reconstructing why each release introduced it.

## Gap / Observation V11-6: Runtime files were missing while meta and project-owned files were shipped

**Symptom**: CLI installs omitted `.speck/reference` even though AGENTS, skills, and the context loader require it. The same sync overwrote `.speck/patterns`, and the template exporter copied the entire evaluation workspace while generating invalid cross-host agent links.

**Reproduction**: Compare `packages/cli/lib/sync.js` and `export-template-repo.sh` with every path referenced by shipped AGENTS and skills; run a clean export and inspect its contents.

**Root cause**: `.speck/` was organized by historical accretion rather than downstream ownership and load behavior.

**Severity**: P1

**Patch applied**: Ship `.speck/reference`; move methodology evaluation to `tests/eval`; move release history, feedback, and framework learnings under `docs`; stop seeding or overwriting project-learned patterns; curate template export; add sync/export regression tests and missing validation references.

**Impact**: The installed runtime dependency graph closes, meta evidence no longer masquerades as product context, and project memory survives upgrades.
