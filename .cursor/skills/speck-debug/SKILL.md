# speck-debug

Cheap keys: debug phase (triage → hypothesize → evidence → fix). Do not Read later phases early.

1. MUST Read `references/triage.md` first (classify failure).
2. After symptoms classified: MUST Read `references/hypotheses.md`.
3. Before claiming root cause: MUST Read `references/evidence.md` (repro required).
4. Only after root cause is evidenced: MUST Read `references/fix-loop.md`; fix + verify.
