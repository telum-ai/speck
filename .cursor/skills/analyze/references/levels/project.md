# Project analysis scope

Load whichever project artifacts exist: `project.md`, `PRD.md`, `epics.md`, `product-contract.md`, `context.md`, `architecture.md`, `evidence-contract.md`, `project-roadmap.md`, `project-landscape-overview.md`, `project-decisions-log.md`. Record `git rev-parse HEAD` as `analyzed_sha`.

The target is the project planning corpus. Judge whether the project promises, epic set, constraints, architecture, and evidence plan can all be satisfied together. Do not inspect epic implementation detail except where it proves an ownership or coverage contradiction.
