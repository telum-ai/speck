# Story analysis scope

Load `spec.md`, `plan.md`, `tasks.md`, optional `ui-spec.md`, `data-model.md`, `contracts/`, code scans, inherited constitutions, epic breakdown, and the story's traceability rows. Record `git rev-parse HEAD` as `analyzed_sha`.

Judge whether the promised behavior, technical design, executable tasks, failure paths, and project constraints can be satisfied together before implementation begins. This is independent planning evaluation; post-implementation truth still belongs to `/speck-audit`.
