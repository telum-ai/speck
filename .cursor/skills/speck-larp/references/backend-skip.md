# speck-larp / backend route

Backend-only projects do not run UI persona LARP and cannot claim UX-RC, FELT-GOOD, or TASTE.

1. Read `evidence-contract.md` integration/stress scenarios and the target readiness criteria.
2. Execute each scenario against the required built/deployed substrate with the named principal, negative control, and telemetry.
3. Prove acceptance, authorization, persistence, failure posture, idempotency/retry bounds, migrations, and observability where applicable.
4. Save command/request, response, logs, read-back, timings, and environment/build SHA under the declared evidence path; SHA-stamp the findings.
5. Any human-facing drawn surface changes the route: STOP and run the UI LARP nodes instead.
6. Return API-RC/OPERATIONAL readiness evidence to the calling validate skill. Do not manufacture a UI-axis verdict.
