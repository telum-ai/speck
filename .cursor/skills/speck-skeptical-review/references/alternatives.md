# Alternatives

1. State one crisp decision question. Name the persona/job, contract constraint, evidence constraint, and boundary that make options comparable.
2. Generate at least three materially different, plausible, in-scope mechanisms. Renames and parameter tweaks of one mechanism count as one.
3. Include the untreated/status-quo option when it is plausible. Include a boundary-changing option only when the boundary itself is open.
4. For each option, state the mechanism, strongest advantage, likely failure mode, and what evidence would falsify it.
5. Reject an option only with a named contract conflict, evidence failure, or prohibitive constraint. Familiarity and recipe precedent are not reasons.
6. If fewer than three survive, widen the mechanism search. Do not lock yet.

Return the complete candidate set to the caller. Selection happens only on the lock branch.
